# Practice-Company-Prep-cyber


Company Map:
  Numata is an international security company. The company offers various security services to organisations which seek or require network security. 

90-sec SOC drill:
  The SOC team is responsible for detecting and responding to any possible threats to the network. 
  This is done through various processes of monitoring, alerting and triaging.
  Another role of a SOC team is to turn raw data into readable and understandable data. This data can be used for reporting and mitigating vulnerabilities. 
  
AI in SOC:
  AI can be very beneficial in SOC teams because it can lighten the load of a lot of work.
  AI can be used to increase productivity and its method of implementation does not have to replace the humans initially tasked with such work.

Alert Triage Mini-lab:
  I completed a TryHackMe mini-lab which was focused on triaging an attack on a network.
  The organisation received an alert about a reverse shell outbound connection and I had to discover the origin and movement of the attack.
  The attacker managed to enter the system and extract some data, this whole process had to be detected and documented.

Evidence Pack Template:
  POPIA is a law which is meant to protect users' private information.
  CIS controls can be used to maintain organisation security.
  A good evidence pack follows these two frameworks to give as much information about the attack without releasing confidential information.
  This pack contains a template which may be used for a junior analyst's report.

SOC Analyst vs Penetration Test:

  This is a comparison between the average day-to-day operations between the two roles.
