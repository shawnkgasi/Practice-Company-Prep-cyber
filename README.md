# Practice-Company-Prep-cyber


Company Map:
  Numata is an international security company. The company offers various security services to organisations which seek or require network security. 

90-sec SOC drill:
  The SOC team is responsible for detecting and responding to any possible threats to the network. 
  This is done through various processes of monitoring, alerting and triaging.
  Another role of a SOC team is to turn raw data into readable and understandable data. This data can be used for reporting and mitigating vulnerabilities.
